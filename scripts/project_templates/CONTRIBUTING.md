# Contributing

Agree on this project's contribution process before accepting changes.
Read [AGENTS.md](AGENTS.md), define the scope and verification in
[docs/PRD.md](docs/PRD.md), and record actual checks in
[docs/QUALITY_GATES.md](docs/QUALITY_GATES.md).

The [PR template](.github/pull_request_template.md) provides change, verification
and rollback prompts. Keep reports free of credentials and private project data.
No branch protection, reporting channel or application CI policy is preconfigured.
